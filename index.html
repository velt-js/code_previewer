Welcome to Code Preview

To use this tool, you can provide the following URL parameters (or use the inputs below):

  • github (optional): URL of the GitHub repository
  • preview (optional): URL of the preview/output page
  • hideToolbar (optional): Set to 'true' to hide the toolbar
  • selectedTab (optional): Set to 'Code' or 'Preview' to select the initial tab
  • themeColor (optional): Hex color like '1A2A7C'

Example URL:

https://yourpage.com?github=https://github.com/user/repo&preview=https://preview-url.com&hideToolbar=true&selectedTab=Code&themeColor=1A2A7C
